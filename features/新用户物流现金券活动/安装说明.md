# 安装说明

将整个“新用户物流现金券活动”目录复制到目标 Nuxt 项目的 `features` 目录。

## 1. 增加运行开关

在 `nuxt.config.ts` 的 `runtimeConfig.public` 中加入：

```ts
newUserShippingCouponEnabled:
  process.env.NUXT_PUBLIC_NEW_USER_SHIPPING_COUPON_ENABLED !== 'false'
```

## 2. 在首页按需加载

在首页的 `<script setup>` 中加入：

```ts
import { computed, defineAsyncComponent } from 'vue'
import { isNewUserShippingCouponActivityEnabled } from '~/features/新用户物流现金券活动/config'

const ShippingCouponPopup = defineAsyncComponent(() => (
  import('~/features/新用户物流现金券活动/ShippingCouponPopup.vue')
))
const runtimeConfig = useRuntimeConfig()
const newUserShippingCouponActivityEnabled = computed(() => (
  isNewUserShippingCouponActivityEnabled(
    runtimeConfig.public.newUserShippingCouponEnabled
  )
))
```

在首页模板底部加入：

```vue
<ShippingCouponPopup v-if="newUserShippingCouponActivityEnabled" />
```

## 3. 关闭展示

在 `.env` 中设置：

```env
NUXT_PUBLIC_NEW_USER_SHIPPING_COUPON_ENABLED=false
```

然后重新启动 Nuxt 服务。关闭时组件不会渲染，异步弹窗代码也不会加载。

## 4. 会员端和后台

这个压缩包负责首页弹窗展示。注册后发券、一人一次、首单资格和取消订单后作废，仍需要会员前端与真实 API 后台配合执行。
